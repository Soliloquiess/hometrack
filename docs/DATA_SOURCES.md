2. **정책마다 소득 판정 지표 자체가 다르다.** 도시근로자 가구당 월평균소득(행복주택·국민임대 일부), 기준중위소득(통합공공임대 일반/우선공급), 단순 연소득 상한(버팀목·디딤돌·신생아특례), 부부합산 상한(부산시 자체 사업) 등이 혼재한다. 자격 자동판정 기능을 넣을 경우 정책별 지표를 명확히 구분해야 한다.
3. **예비신혼부부 인정 조건이 정책마다 다르다.** "혼인계획 증빙 + 입주 전 혼인신고"(행복주택), "혼인예정 3개월"(부산시 사업), "3개월 이내 결혼예정"(버팀목) 등 세부 요건이 다르므로, 사이트에서 일괄 판정하지 말고 "정확한 인정조건은 해당 공고문·상품설명서 확인 필요"라는 안내 문구를 넣어야 한다.
4. **자산기준(총자산/순자산, 자동차가액)은 주택유형별로 액수가 다르고 매년 갱신된다.** 행복주택 자동차가액(4,542만원)과 국민임대·통합공공임대 자동차가액(3,708만원)이 서로 다르므로 하드코딩 시 유형별로 분리 저장하고, 연 1회(가계금융복지조사 발표 후) 갱신 프로세스를 마련해야 한다.
5. **부산시 자체 정책(럭키7하우스, 신혼부부 주택융자·대출이자 지원)은 상시 API가 아니라 회차별 공고로 운영된다.** 소득기준·모집세대수·접수기간이 공고마다 바뀌므로, 자동 수집이 아니라 부산시 정책 페이지(A-6 목록)를 정기적으로(예: 주 1회) 사람이 확인하거나 변경 감지 크롤러로 모니터링하는 반자동 체계가 필요하다.
